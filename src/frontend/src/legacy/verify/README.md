# Inactive Verify UI

These components are preserved for possible future reuse, but Verify and the
ID-card scanner are not registered as active App routes. Relocation does not
reenable them. `verify.css` remains imported for presentation compatibility.

Backend verification modules are retained separately; moving this UI does not
disable API endpoints or delete any user data. See the
[project map](../../../../../docs/PROJECT_STRUCTURE.md).
